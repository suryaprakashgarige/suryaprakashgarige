## // ABOUT THE ENGINEER

I'm **Surya Prakash Garige**, an aeronautical engineering student interested in turning engineering theory into tools, simulations, and reproducible experiments.

- ✈️ **Aerodynamics:** airfoils, wings, and aerodynamic performance
- 🌊 **CFD:** learning and applying computational fluid dynamics with OpenFOAM and ParaView
- 🧠 **Aerospace + AI/ML:** exploring data-driven methods alongside physics-based models
- 🛰️ **Flight & space systems:** UAV simulation, mission planning, and orbital mechanics
- 💻 **Software:** Python, Java, and web technologies for engineering workflows

> My goal: understand the physics, validate the model, and make the results useful.

## // RESEARCH LAB

Current technical interests:

- **Airfoil and wing aerodynamics** — connecting 2D airfoil data with 3D lifting-line analysis.
- **Turbulence modelling and CFD validation** — comparing numerical predictions with trusted reference or experimental data.
- **AI-assisted engineering** — using machine learning where it adds value, while keeping physical assumptions and limitations explicit.
- **UAV and space mission simulation** — modelling vehicle behaviour, navigation, and mission performance.

I aim to publish work only when the methods, assumptions, and results are sufficiently validated and documented.
